# ISAGI🌱GAME - 小草的游戏园

## 项目介绍

ISAGI🌱GAME 是一个充满趣味的小游戏集合网站，包含多种类型的休闲游戏，适合所有年龄段的用户。网站采用现代化的设计风格，具有响应式布局，可在PC端和手机端完美适配。

## 游戏分类

### 益智类
- 小草吞吞乐
- 努努对对碰

### 射击类
- 虾虾保卫战
- 战虾！！！

### 眼力类
- 寻找色虾
- 不一样的小土豆

### 运气类
- 努匹配

## 技术特点

1. **现代化设计**：采用渐变背景和卡片式布局，视觉效果美观
2. **响应式设计**：适配PC端、平板和手机等各种设备
3. **统一的样式风格**：所有游戏页面采用统一的设计语言
4. **流畅的动画效果**：按钮和元素具有平滑的过渡动画
5. **良好的用户体验**：简洁直观的界面，易于操作

## 如何运行

1. 克隆或下载项目到本地
2. 使用浏览器打开 `index.html` 文件
3. 选择喜欢的游戏开始游玩

## 浏览器兼容性

- Firefox 55+
- Safari 12+
- Edge 79+
